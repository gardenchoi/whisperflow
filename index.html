# WhisperFlow 만들기: 내 컴퓨터용 무료 받아쓰기 앱

친구가 Claude와 함께 "WhisperFlow"라는 받아쓰기 앱을 만들어서 쓰고 있어. Wispr Flow처럼 키를 누른 채 말하면, 지금 커서가 있는 곳(카톡, 메일, 메모, 브라우저 등 어디든)에 받아쓴 글이 입력되는 앱이야. 음성 인식은 전부 내 컴퓨터 안에서 처리하고, 무료야.

**나도 똑같은 앱을 이 컴퓨터에 만들어서 설치해 줘. 설치가 끝나면 직접 테스트까지 해 줘.**

아래에 기능 명세, 친구가 쓰면서 겪은 문제와 해결법, 컴퓨터 종류별 구현 가이드, 그리고 Windows 버전 전체 코드를 정리해 뒀어. 코드는 참고용이야. 이 컴퓨터 환경에 맞게 바꿔야 할 부분이 있어.

나는 개발자가 아닐 수도 있어. 설명은 쉬운 한국어로 해 줘. 프로그램 설치나 권한 허용처럼 내가 직접 눌러야 하는 게 있으면 어디를 눌러야 하는지 단계별로 알려 주고, 시스템에 무언가를 설치하기 전에는 먼저 물어봐 줘.

1. 이 컴퓨터의 운영체제(Windows/macOS), CPU, 메모리, 그래픽카드(NVIDIA 여부), 남은 저장 공간을 확인해 줘.
2. 아래 "4. 컴퓨터 종류별 구현"에서 맞는 방식을 골라 나에게 짧게 설명해 줘. 예상 속도, 필요한 용량(대략 2~4GB), 설치할 것들을 알려 주고 진행해.
3. 녹음 키는 기본으로 `` ` `` 키(숫자 1 왼쪽, 백틱)를 써. 이 키를 자주 쓰는지 나에게 물어보고, 쓴다면 다른 키를 같이 정해 줘.

## 1. 기능 명세 (꼭 지켜 줘)

1. **누르고 말하기:** 녹음 키를 누르고 있는 동안 녹음하고, 떼면 받아써서 커서 위치에 입력해.
   - 앱이 켜져 있는 동안 녹음 키는 글자로 입력되면 안 돼. 이벤트를 가로채서 막아 줘.
   - 0.3초보다 짧게 누르면 무시해.
2. **화면에 실시간 표시:**
   - 화면 아래 가운데에 어두운 알약 모양 창을 띄워 줘.
   - 왼쪽에는 목소리 크기에 따라 움직이는 빨간 막대 5개, 오른쪽에는 말하는 동안 인식 중인 글을 계속 갱신해서 보여 줘. 글이 길면 "…"으로 앞부분을 자르고 끝부분을 보여 줘.
   - 키를 떼면 "정리하는 중…"을 보여 주고, 입력이 끝나면 약 1.2초 뒤에 사라져.
   - 이 창은 **포커스를 뺏으면 안 되고**(지금 쓰는 앱의 커서 유지), 클릭이 통과돼야 해.
3. **부드러운 시작음과 종료음:**
   - 옛날 기계음 같은 삑 소리는 싫어.
   - 짧은 두 음 차임으로 해 줘. 시작할 때는 G5에서 D6으로 올라가고, 끝날 때는 D6에서 G5로 내려가.
   - 사인파에 배음을 조금 섞고, 빠른 어택과 부드러운 감쇠를 줘. 길이는 약 0.22초, 볼륨은 작게(0.12).
4. **발화 사이 띄어쓰기:**
   - 같은 앱(창)에 이어서 받아쓰면, 두 번째부터는 앞에 띄어쓰기를 한 칸 넣어 줘.
   - 이전 입력이 공백으로 끝났거나, 새 글이 문장부호로 시작하면 넣지 마.
   - Enter나 Tab을 누르거나 다른 창으로 바꾸면 초기화해 줘.
5. **한국어/영어 자동 인식:**
   - 발화마다 언어를 감지하되, **ko와 en 중에서만** 확률이 높은 쪽을 골라 그 언어로 받아써 줘.
   - `language="ko"`로 고정하면 영어가 한국어로 번역되거나 한글로 적히는 문제가 있었어.
6. **이전 받아쓰기 다시 입력 (터미널 명령 기록처럼):**
   - 실수로 다른 곳을 클릭해서 받아쓴 글이 날아가는 일이 있어서 만든 기능이야.
   - 녹음 키를 누른 채 **↑**를 누르면 녹음을 버리고 '기록 고르기'로 바뀌어. 알약 창에 "↑↓" 표시와 "1/32   (가장 최근 글)"이 떠.
   - ↑/↓로 이동하고, **Enter**를 누르면 그 글을 커서 위치에 입력해. **Esc**를 누르거나 녹음 키를 떼면 취소야.
   - 녹음 키를 누르고 있을 때만 ↑↓/Enter/Esc를 가로채고, 평소에는 그대로 통과시켜.
   - 받아쓴 글은 **붙여넣기 전에 먼저 기록에 저장**해. 그래야 붙일 곳이 없어도 남아.
7. **개인정보:** 받아쓴 내용이 담긴 로그와 기록(history.json)은 **24시간이 지나면 자동으로 지워** 줘.
8. **로그인 시 자동 실행:**
   - 콘솔 창 없이 조용히 켜지게 해 줘.
   - 켜질 때 "WhisperFlow 준비 중…"을 보여 주고, 준비되면 "준비 완료 — (키) 키를 누르고 말하세요"를 2.5초 동안 보여 줘.
9. **트레이(맥은 메뉴 막대) 아이콘:** 여기서 종료할 수 있게 해 줘. 맥은 Dock 아이콘을 숨겨 줘.
10. **중복 실행 방지:** 두 번 실행해도 하나만 켜지게 해 줘.
11. **복사해 둔 내용 보존:** 붙여넣기에 클립보드를 쓰되, 원래 클립보드 내용은 복원해 줘.
12. **아이콘:**
    - 둥근 사각형 배경에 코랄(255,122,89)에서 핑크(240,84,140), 보라(124,77,255)로 가는 대각선 그라데이션을 깔아 줘.

## 2. 겪었던 문제와 해결법 (같은 실수를 반복하지 않게)

- **말하지 않은 말이 입력됨 (가장 중요):**
  - 흐린 말끝, 숨소리, 웅얼거림을 Whisper가 억지로 글로 바꾸다가 "1 2 3 4 5…"처럼 숫자를 세거나, "시청해주셔서 감사합니다" 같은 문장을 지어냈어.
  - 처음에는 숫자를 지우는 필터를 넣었는데 잘못된 방향이었어. 실제로 숫자를 말할 수도 있으니까. **내용으로 거르지 말고 '실제로 들렸는가'로만 걸러 줘.**
  - 해결:
    - ① **initial_prompt(예시 문장)를 쓰지 마.** 웅얼거림만 넣었더니 예시 문장을 그대로 베꼈어. 예시가 없어도 구두점은 잘 찍혀.
    - ② VAD를 엄격하게 해 줘: `vad_filter=True`, `vad_parameters=dict(min_silence_duration_ms=500, speech_pad_ms=200)`. 기본값(2초/0.4초)은 흐린 말끝까지 포함돼.
    - ③ 최종 받아쓰기에서 `word_timestamps=True`, `hallucination_silence_threshold=1.0`, `condition_on_previous_text=False`.
    - ④ **단어별 확신도로 걸러 줘.** 측정해 보니 실제 말은 평균 0.93~0.99, 지어낸 문장은 0.11~0.36이었어. 그래서 덩어리(segment)의 평균이 0.5 미만이면 버리고, 0.3 미만인 단어가 4개 이상 연달아 나오면 그 구간을 버려(코드의 `confident_text`).
    - ⑤ 미리보기는 빠른 설정(beam 1)으로 하고, `avg_logprob <= -1.0`인 덩어리는 버려. 오디오가 1초 이상 쌓인 뒤에 시작해.
    - ⑥ 유튜브 환각 문구는 **그 문장만 단독으로 나왔을 때만** 버려.
  - 검증: 무음, 잡음, 웅얼거림(말소리를 거꾸로 뒤집고 작게 한 뒤 잡음을 섞은 것)은 빈 결과가 나와야 해. "말 + 웅얼거림"은 말한 부분만 나와야 하고, "인증번호는 1, 2, 3, 4, 5, 6, 7, 8이에요"는 숫자까지 그대로 나와야 해.
- **부팅 직후 먹통:**

def make_chime(path, notes):
    """부드럽게 사라지는 짧은 두 음 차임을 wav 파일로 만든다."""
    sr = 44100
    total = int(sr * 0.22)
    buf = np.zeros(total)
    for i, freq in enumerate(notes):
        start = int(sr * 0.06 * i)
        t = np.arange(total - start) / sr
        env = np.exp(-t * 28) * np.minimum(1, t / 0.004)   # 빠른 어택, 부드러운 감쇠
        tone = np.sin(2 * np.pi * freq * t) + 0.25 * np.sin(4 * np.pi * freq * t)
        buf[start:] += tone * env
    buf = buf / np.max(np.abs(buf)) * SOUND_VOLUME
    with wave.open(path, "wb") as w:
        w.setnchannels(1)
        w.setsampwidth(2)
        w.setframerate(sr)
        w.writeframes((buf * 32767).astype(np.int16).tobytes())

class Recorder:
    def __init__(self):
        self.frames = []
        self.level = 0.0
        self.lock = threading.Lock()
        self.stream = None

    def _callback(self, data, *_):
        with self.lock:
            self.frames.append(data.copy())
        self.level = float(np.sqrt(np.mean(data ** 2)))

    def _open(self):
        self.stream = sd.InputStream(samplerate=SAMPLE_RATE, channels=1,
                                     dtype="float32", callback=self._callback)
        self.stream.start()

    def start(self):
        self.frames = []
        self.stream = None
        try:
            self._open()
        except Exception as e:
            # 부팅 직후 USB 헤드셋이 늦게 잡히거나, 헤드셋을 다시 꽂으면
            # 예전 장치 목록이 남아 있으므로 목록을 새로 읽고 다시 시도
            log(f"마이크 열기 실패, 장치 목록 새로 읽는 중: {e}")
            sd._terminate()
            sd._initialize()
            self._open()

    def snapshot(self):
        with self.lock:
            if not self.frames:
                return np.zeros(0, dtype=np.float32)
            return np.concatenate(self.frames).flatten()

    def stop(self):
        if self.stream is not None:
            try:
                self.stream.stop()
                self.stream.close()
            except Exception as e:
                log(f"마이크 닫기 오류: {e}")
            self.stream = None
        self.level = 0.0
        return self.snapshot()


class Transcriber:

            try:
                log(f"모델 불러오는 중... ({MODEL}, {device}/{compute})")
                self.model = WhisperModel(MODEL, device=device, compute_type=compute)
                list(self.model.transcribe(np.zeros(SAMPLE_RATE, dtype=np.float32), language="ko")[0])
                log(f"준비 완료 ({device})")
                return
            except Exception as e:
                log(f"  {device}/{compute} 사용 불가: {e}")
        raise RuntimeError("모델을 불러올 수 없습니다.")

    def detect(self, audio):
        """한국어/영어 중 더 가능성 높은 쪽을 고른다."""
        with self.lock:
            _, _, probs = self.model.detect_language(audio[: SAMPLE_RATE * 30])
        probs = dict(probs)
        return max(LANGUAGES, key=lambda l: probs.get(l, 0.0))

    def transcribe(self, audio, language, final):
        """말소리가 실제로 들린 부분만 받아쓴다.
        예시 문장(initial_prompt)은 쓰지 않음: 말이 불분명하면 예시를 베껴 쓰는 원인이었음."""
        with self.lock:
            segments, _ = self.model.transcribe(
                audio, language=language,
                initial_prompt=None,
                vad_filter=True,
                # 말이 끝나고 0.5초 넘게 조용하면 거기서 끊음 (기본값 2초는 흐린 말끝·숨소리까지 포함됨)

                if final:

                else:

# 단어별 확신도(0~1) 기준. 실제 말은 평균 0.93~0.99, 지어낸 문장은 0.11~0.36이었음.
MIN_SEGMENT_CONFIDENCE = 0.5   # 한 덩어리의 평균 확신도가 이보다 낮으면 통째로 버림
MIN_WORD_CONFIDENCE = 0.3      # 이보다 낮은 단어가 4개 이상 연달아 나오면 그 구간을 버림


def confident_text(words):
    """Whisper가 확신하지 못한(=실제로 들리지 않은) 부분을 뺀 글을 돌려준다.
    내용(숫자인지 등)은 보지 않고, 오직 '들렸는가'로만 판단."""
    if not words:
        return ""
    if sum(w.probability for w in words) / len(words) < MIN_SEGMENT_CONFIDENCE:
        return ""
    keep, run = [], []
    for w in words:
        if w.probability < MIN_WORD_CONFIDENCE:
            run.append(w)
            continue
        if len(run) < 4:
            keep.extend(run)
        run = []
        keep.append(w)
    if len(run) < 4:
        keep.extend(run)
    return "".join(w.word for w in keep).strip()

class Paster:
    """같은 창에 이어서 받아쓰면 앞에 띄어쓰기를 한 칸 넣는다."""

    def __init__(self):
        self.last_hwnd = None
        self.last_char = ""
        # 엔터/탭을 누르거나 창을 바꾸면 '이어쓰기'가 아닌 것으로 봄
        keyboard.on_press_key("enter", lambda e: self.reset())
        keyboard.on_press_key("tab", lambda e: self.reset())

    def reset(self):
        self.last_hwnd = None

    def paste(self, text):
        hwnd = user32.GetForegroundWindow()
        if (SPACE_BETWEEN_UTTERANCES and hwnd == self.last_hwnd
                and self.last_char and not self.last_char.isspace()
                and text[:1] not in ".,!?;:)]}'\"。"):
            text = " " + text

        old = None
        try:
            old = pyperclip.paste()
        except Exception:
            pass
        pyperclip.copy(text)
        time.sleep(0.05)
        keyboard.send("ctrl+v")
        time.sleep(0.3)
        if old is not None:
            pyperclip.copy(old)  # 원래 클립보드 내용 복원

        self.last_hwnd = hwnd
        self.last_char = text[-1:]

class History:
    """받아쓴 글을 순서대로 보관. 컴퓨터를 껐다 켜도 남도록 파일에 저장.
    로그와 똑같이 LOG_KEEP_HOURS가 지난 것은 지움."""

    PATH = os.path.join(APP_DIR, "history.json")
    MAX = 100

    def __init__(self):
        self.items = []   # [{"t": 시각, "text": 글}, …] 오래된 것 → 최근 것
        self.lock = threading.Lock()
        try:
            with open(self.PATH, encoding="utf-8") as f:
                self.items = json.load(f)
        except FileNotFoundError:
            self.items = self._from_log()   # 처음 한 번: 기록 파일에 남아 있는 것을 가져옴
        except Exception:
            pass
        with self.lock:
            self._prune()
            self._save()

    @staticmethod
    def _from_log():
        import re
        pattern = re.compile(r"^\[(\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})\] \[(?:ko|en), [\d.]+초\] (.+)$")
        items = []
        try:
            with open(LOG_PATH, encoding="utf-8") as f:
                for line in f:
                    m = pattern.match(line.rstrip("\n"))
                    if m:
                        t = time.mktime(time.strptime(m.group(1), "%Y-%m-%d %H:%M:%S"))
                        items.append({"t": t, "text": m.group(2)})
        except Exception:
            pass
        return items

    def _prune(self):
        cutoff = time.time() - LOG_KEEP_HOURS * 3600
        self.items = [i for i in self.items if i.get("t", 0) >= cutoff][-self.MAX:]

    def _save(self):
        try:
            tmp = self.PATH + ".tmp"
            with open(tmp, "w", encoding="utf-8") as f:
                json.dump(self.items, f, ensure_ascii=False, indent=0)
            os.replace(tmp, self.PATH)
        except Exception as e:
            log(f"기록 저장 오류: {e}")

    def prune_forever(self):
        while True:
            time.sleep(3600)
            with self.lock:
                self._prune()
                self._save()

    def add(self, text):
        with self.lock:
            self.items.append({"t": time.time(), "text": text})
            self._prune()
            self._save()

    def get(self, back):
        """back=0이 가장 최근, 1이 그 이전…"""
        with self.lock:
            self._prune()
            return self.items[-1 - back]["text"] if 0 <= back < len(self.items) else None

    def __len__(self):
        with self.lock:
            self._prune()
            return len(self.items)

class Overlay:
    """화면 아래에 뜨는 반투명 알약 모양 창. 포커스를 뺏지 않고 클릭도 통과시킨다."""

    WIDTH = 620

    def __init__(self, root):
        self.root = root
        self.scale = root.winfo_fpixels("1i") / 96
        s = self.scale
        self.w = int(self.WIDTH * s)
        self.h = int(64 * s)

        root.overrideredirect(True)
        root.attributes("-topmost", True)
        root.attributes("-transparentcolor", KEY)
        root.attributes("-alpha", 0.0)
        root.configure(bg=KEY)

        self.canvas = tk.Canvas(root, bg=KEY, highlightthickness=0, width=self.w, height=self.h)
        self.canvas.pack()
        self.font = ("Malgun Gothic", 11)
        self.visible = False
        self.state = "idle"
        self.text = ""
        self.level = 0.0
        self.hide_at = None
        self.phase = 0.0
        self._layout()

        root.update_idletasks()
        hwnd = user32.GetParent(root.winfo_id())
        GWL_EXSTYLE = -20
        style = user32.GetWindowLongW(hwnd, GWL_EXSTYLE)
        # WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW | WS_EX_TRANSPARENT | WS_EX_LAYERED
        user32.SetWindowLongW(hwnd, GWL_EXSTYLE, style | 0x08000000 | 0x80 | 0x20 | 0x80000)

    def _layout(self):
        sw, sh = self.root.winfo_screenwidth(), self.root.winfo_screenheight()
        x = (sw - self.w) // 2
        y = sh - self.h - int(90 * self.scale)
        self.root.geometry(f"{self.w}x{self.h}+{x}+{y}")

    def _round_rect(self, x1, y1, x2, y2, r, **kw):
        c = self.canvas
        c.create_oval(x1, y1, x1 + 2 * r, y1 + 2 * r, **kw)
        c.create_oval(x2 - 2 * r, y1, x2, y1 + 2 * r, **kw)
        c.create_oval(x1, y2 - 2 * r, x1 + 2 * r, y2, **kw)
        c.create_oval(x2 - 2 * r, y2 - 2 * r, x2, y2, **kw)
        c.create_rectangle(x1 + r, y1, x2 - r, y2, **kw)
        c.create_rectangle(x1, y1 + r, x2, y2 - r, **kw)

    def show(self, state, text="", hide_after=None):
        self.state = state
        self.text = text
        self.hide_at = time.time() + hide_after if hide_after else None
        if not self.visible:
            self.root.attributes("-alpha", 0.94)
            self.visible = True

    def hide(self):
        self.visible = False
        self.state = "idle"
        self.root.attributes("-alpha", 0.0)

    def draw(self):
        c, s = self.canvas, self.scale
        c.delete("all")
        if not self.visible:
            return
        if self.hide_at and time.time() > self.hide_at:
            self.hide()
            return

        r = self.h // 2
        self._round_rect(0, 0, self.w - 1, self.h - 1, r, fill=BG, outline=BG)

        # 왼쪽: 녹음 중이면 소리 크기에 따라 움직이는 막대, 처리 중이면 점 세 개
        cx, cy = int(34 * s), self.h // 2
        self.phase += 0.35
        if self.state == "history":
            c.create_text(cx, cy, text="↑↓", fill=ACCENT, font=(self.font[0], 12, "bold"))
        elif self.state == "recording":
            lvl = min(1.0, self.level * 18)
            for i, off in enumerate((-12, -6, 0, 6, 12)):
                wob = 0.55 + 0.45 * math.sin(self.phase + i * 1.3)
                bh = max(3, (4 + 20 * lvl * wob)) * s
                x = cx + off * s
                c.create_line(x, cy - bh / 2, x, cy + bh / 2, fill=ACCENT,
                              width=max(2, int(3 * s)), capstyle="round")
        else:
            for i in range(3):
                a = 0.5 + 0.5 * math.sin(self.phase - i * 0.9)
                color = FG if (self.state == "processing" and a > 0.6) else FG_DIM
                x = cx + (i - 1) * 9 * s
                c.create_oval(x - 2.5 * s, cy - 2.5 * s, x + 2.5 * s, cy + 2.5 * s,
                              fill=color, outline=color)

        # 오른쪽: 글. 길면 잘라서 보여줌
        # (인식 중에는 끝부분, 기록을 고를 때는 앞부분이 보이게)
        text = self.text or {"recording": "듣고 있어요…", "processing": "정리하는 중…"}.get(self.state, "")
        color = FG if self.text else FG_DIM
        max_w = self.w - int(80 * s)
        item = c.create_text(int(64 * s), cy, text=text, fill=color, font=self.font, anchor="w")
        if c.bbox(item)[2] - c.bbox(item)[0] > max_w:
            keep_start = self.state == "history"
            cut = (lambda n: text[:len(text) - n] + "…") if keep_start else (lambda n: "…" + text[n:])
            lo, hi = 0, len(text)
            while lo < hi:
                mid = (lo + hi) // 2
                c.itemconfigure(item, text=cut(mid))
                bb = c.bbox(item)
                if bb[2] - bb[0] > max_w:
                    lo = mid + 1
                else:
                    hi = mid
            c.itemconfigure(item, text=cut(lo))

class App:
    def __init__(self):
        self.root = tk.Tk()
        self.overlay = Overlay(self.root)
        self.recorder = Recorder()
        self.transcriber = Transcriber()
        self.paster = None
        self.events = queue.Queue()        # 다른 스레드 → 화면 갱신
        self.finals = queue.Queue()        # 받아쓸 녹음들 (순서대로 처리)
        self.key_down = threading.Event()
        self.recording = False
        self.mic_failed = False
        self.ready = False
        self.history = History()
        threading.Thread(target=self.history.prune_forever, daemon=True).start()
        # 녹음 키를 누르고 있는 동안의 상태:
        #   idle → recording (말하는 중) → history (↑↓로 이전 기록 고르는 중) → wait_release (입력/취소 후 키 떼기 기다림)
        self.mode = "idle"
        self.hist_index = 0

        self.tray = pystray.Icon("WhisperFlow", tray_image(), "WhisperFlow (준비 중)",
                                 menu=pystray.Menu(pystray.MenuItem("종료", self.quit)))
        self.tray.run_detached()

        threading.Thread(target=self.startup, daemon=True).start()
        self.tick()

    # 모델 불러오기 → 키 등록
    def startup(self):
        self.events.put(("show", "processing", "WhisperFlow 준비 중…", None))
        try:
            self.transcriber.load()
        except Exception as e:
            log(str(e))
            self.events.put(("show", "idle", "모델을 불러오지 못했어요. 로그를 확인해 주세요.", 8))
            return
        self.paster = Paster()
        # suppress=True: 녹음 키가 글자로 입력되지 않도록 가로챔
        keyboard.on_press_key(HOTKEY, lambda e: self.key_down.set(), suppress=True)
        keyboard.on_release_key(HOTKEY, lambda e: self.key_down.clear(), suppress=True)
        # 녹음 키를 누르고 있을 때만 ↑ ↓ Enter Esc를 가로채서 기록 고르기에 씀.
        # 녹음 키를 안 누르고 있으면 평소처럼 그대로 통과.
        for name in ("up", "down", "enter", "esc"):
            keyboard.hook_key(name, lambda e, n=name: self.on_nav_key(e, n), suppress=True)
        threading.Thread(target=self.final_worker, daemon=True).start()
        self.ready = True
        self.tray.title = f"WhisperFlow — {HOTKEY_LABEL} 키를 누르고 말하세요"
        self.events.put(("show", "idle", f"준비 완료 — {HOTKEY_LABEL} 키를 누르고 말하세요", 2.5))

    # 화면 갱신 + 키 상태 확인 (약 30fps)
    def tick(self):
        while not self.events.empty():
            kind, *args = self.events.get()
            if kind == "show":
                state, text, hide_after = args
                self.overlay.show(state, text, hide_after)
            elif kind == "partial" and self.recording:
                self.overlay.text = args[0]
            elif kind == "hide":
                self.overlay.hide()
            elif kind == "nav":
                try:
                    self.handle_nav(args[0])
                except Exception as e:
                    log(f"기록 고르기 오류: {e}")
            elif kind == "quit":
                self.root.destroy()
                return

        # 오류가 나도 화면 갱신 루프는 절대 멈추지 않게 함
        try:
            if self.ready:
                if not self.key_down.is_set():
                    if self.mode == "recording":
                        self.stop_recording()
                    elif self.mode == "history":
                        self.overlay.hide()       # 고르다가 키를 떼면 취소
                    self.mode = "idle"
                    self.mic_failed = False
                elif self.mode == "idle" and not self.mic_failed:
                    self.start_recording()

            self.overlay.level = self.recorder.level
            self.overlay.draw()
        except Exception as e:
            log(f"화면 갱신 오류: {e}")
        self.root.after(33, self.tick)

    def start_recording(self):
        try:
            self.recorder.start()
        except Exception as e:
            log(f"마이크를 열 수 없음: {e}")
            self.mic_failed = True   # 키를 뗄 때까지 다시 시도하지 않음
            self.overlay.show("idle", "마이크를 찾을 수 없어요. 헤드셋 연결을 확인해 주세요.", 3)
            return
        play(SOUND_START)
        self.recording = True
        self.mode = "recording"
        self.t0 = time.time()
        self.overlay.show("recording")
        threading.Thread(target=self.partial_worker, daemon=True).start()

    def cancel_recording(self):
        """녹음을 버림 (받아쓰지 않음)."""
        if self.recording:
            self.recording = False
            self.recorder.stop()

    # ── 이전 기록 고르기: 녹음 키를 누른 채 ↑↓, Enter로 입력, Esc나 키 떼기로 취소 ──

    def on_nav_key(self, event, name):
        """키보드 스레드에서 불림. True면 키를 그대로 통과, False면 가로챔."""
        if not (self.ready and self.key_down.is_set()):
            return True
        if event.event_type == "down":
            self.events.put(("nav", name))
        return False

    def handle_nav(self, name):
        if self.mode == "wait_release":
            return
        if name in ("up", "down"):
            if self.mode != "history":
                self.cancel_recording()
                self.mode = "history"
                self.hist_index = 0
            elif name == "up":
                self.hist_index = min(self.hist_index + 1, len(self.history) - 1)
            else:
                self.hist_index = max(self.hist_index - 1, 0)
            self.show_history()
        elif name == "enter" and self.mode == "history":
            text = self.history.get(self.hist_index)
            self.mode = "wait_release"
            if text:
                self.overlay.show("done", text, 1.2)
                threading.Thread(target=self.paster.paste, args=(text,), daemon=True).start()
            else:
                self.overlay.hide()
        elif name == "esc":
            self.cancel_recording()
            self.mode = "wait_release"
            self.overlay.hide()

    def show_history(self):
        n = len(self.history)
        if n == 0:
            self.overlay.show("history", "아직 받아쓴 기록이 없어요")
            return
        text = self.history.get(self.hist_index)
        self.overlay.show("history", f"{self.hist_index + 1}/{n}   {text}")

    def stop_recording(self):
        self.recording = False
        audio = self.recorder.stop()
        play(SOUND_STOP)
        if time.time() - self.t0 < MIN_SECONDS:
            self.overlay.hide()
            return
        # 마이크가 하드웨어로 꺼져 있으면(헤드셋 음소거 버튼 등) Windows는 모르고 무음만 들어옴.
        # 조용한 방도 보통 0.003 이상이 나오므로, 이보다 훨씬 작으면 마이크가 꺼진 것으로 봄.
        peak = float(np.abs(audio).max()) if len(audio) else 0.0
        if peak < 0.0005:
            log(f"마이크에 소리가 안 들어옴 (최대 {peak:.6f})")
            self.overlay.show("idle", "마이크에 소리가 안 들어와요. 헤드셋 음소거 버튼을 확인해 주세요.", 4)
            return
        self.overlay.show("processing", self.overlay.text)
        self.finals.put(audio)

    # 말하는 동안 계속 받아써서 화면에 보여줌 (빠른 모드)
    def partial_worker(self):
        language = None
        while self.recording:
            audio = self.recorder.snapshot()
            if len(audio) < SAMPLE_RATE * 1.0:
                time.sleep(0.1)
                continue
            try:
                if language is None and len(audio) >= SAMPLE_RATE * 1.5:
                    language = self.transcriber.detect(audio)
                text = self.transcriber.transcribe(audio[-SAMPLE_RATE * 25:],
                                                   language or LANGUAGES[0], final=False)
                if self.recording:
                    self.events.put(("partial", text))
            except Exception as e:
                log(f"미리보기 오류: {e}")
                time.sleep(0.5)

    # 키를 떼면 정확한 모드로 다시 받아써서 붙여넣음
    def final_worker(self):
        while True:
            audio = self.finals.get()
            try:
                started = time.time()
                language = self.transcriber.detect(audio)
                text = self.transcriber.transcribe(audio, language, final=True)
                if text:
                    self.history.add(text)   # 붙여넣을 곳이 없어도 기록에는 남김
                    self.paster.paste(text)
                    log(f"[{language}, {time.time() - started:.1f}초] {text}")
                    if self.mode == "idle":
                        self.events.put(("show", "done", text, 1.2))
                else:
                    log("(인식된 말이 없습니다)")
                    if self.mode == "idle":
                        self.events.put(("hide",))
            except Exception as e:
                log(f"오류: {e}")
                if self.mode == "idle":
                    self.events.put(("hide",))

    def quit(self, *_):
        log("트레이 메뉴에서 종료를 눌렀습니다")
        self.tray.stop()
        keyboard.unhook_all()
        self.events.put(("quit",))

    def run(self):
        self.root.mainloop()
        log("앱 종료")
        os._exit(0)

    pad = int(N * 0.04)
    mask = Image.new("L", (N, N), 0)
    ImageDraw.Draw(mask).rounded_rectangle((pad, pad, N - pad, N - pad), radius=int(N * 0.23), fill=255)
    icon = Image.new("RGBA", (N, N), (0, 0, 0, 0))
    icon.paste(grad, (0, 0), mask)

    # 위쪽에 은은한 광택
    gloss = Image.new("L", (N, N), 0)
    ImageDraw.Draw(gloss).ellipse((-N * 0.3, -N * 0.75, N * 1.3, N * 0.45), fill=34)
    gloss = gloss.filter(ImageFilter.GaussianBlur(N * 0.06))
    gloss = Image.composite(gloss, Image.new("L", (N, N), 0), mask)
    icon = Image.composite(Image.new("RGBA", (N, N), (255, 255, 255, 255)), icon, gloss)
    icon.putalpha(mask)

    # 흰색 음성 파형 막대 + 부드러운 그림자
    bars = [0.26, 0.46, 0.66, 0.46, 0.26]
    bw, gap = int(N * 0.085), int(N * 0.06)
    total = len(bars) * bw + (len(bars) - 1) * gap
    x0, cy = (N - total) // 2, N // 2
    shapes = Image.new("L", (N, N), 0)
    d = ImageDraw.Draw(shapes)
    for i, h in enumerate(bars):
        x = x0 + i * (bw + gap)
        hh = int(N * h / 2)
        d.rounded_rectangle((x, cy - hh, x + bw, cy + hh), radius=bw // 2, fill=255)

    shadow = shapes.filter(ImageFilter.GaussianBlur(N * 0.02)).point(lambda v: v * 0.28)
    shadow = Image.composite(shadow, Image.new("L", (N, N), 0), mask)
    shadow_layer = Image.new("RGBA", (N, N), (40, 10, 60, 255))
    shadow_layer.putalpha(shadow)
    icon.alpha_composite(shadow_layer, (0, int(N * 0.015)))
    white = Image.new("RGBA", (N, N), (255, 255, 255, 255))
    white.putalpha(shapes)
    icon.alpha_composite(white)

    big = icon.resize((256, 256), Image.LANCZOS)
    big.save(os.path.join(APP_DIR, "icon.png"))
    big.save(os.path.join(APP_DIR, "icon.ico"),
             sizes=[(16, 16), (20, 20), (24, 24), (32, 32), (40, 40), (48, 48), (64, 64), (128, 128), (256, 256)])

녹음 키는 기본으로 숫자 1 왼쪽의 `(백틱)이에요. 설치할 때 다른 키로 바꿀 수 있어요.

` 누른 채 말하기

말하는 동안 화면 아래에 글이 보이고, 키를 떼면 커서 자리에 입력돼요.

` + ↑ ↓

이전에 받아쓴 글을 하나씩 찾아봐요. 터미널에서 명령 기록을 찾는 것과 같아요.

` + Enter

고른 글을 커서 자리에 입력해요.

` 떼기 · Esc

고르던 걸 취소해요. 아무것도 입력되지 않아요.

트레이 아이콘 우클릭

앱을 꺼요. 맥은 화면 위쪽 메뉴 막대에 있어요.

문제 해결

실제로 겪었던 것들이에요. 안내문에 해결법이 들어 있지만, 혹시 생기면 이렇게 해 보세요.

`가 글자로 입력돼요

앱이 꺼져 있다는 뜻이에요. 바탕화면(맥은 응용 프로그램)의 WhisperFlow를 다시 실행하세요. 계속 꺼지면 Claude에게 "앱이 저절로 꺼져"라고 말하고 로그를 봐 달라고 하세요.

"마이크에 소리가 안 들어와요"라고 떠요

헤드셋의 마이크 음소거 버튼이 켜져 있을 가능성이 커요. 게임이나 통화 중에 눌러 두고 잊는 경우가 많아요. Windows는 소리 설정 → 입력 → 마이크 테스트에서, 맥은 시스템 설정 → 사운드 → 입력에서 막대가 움직이는지 확인해 보세요.

컴퓨터를 켠 직후에 안 돼요

USB 헤드셋이 늦게 인식되면 생길 수 있어요. 안내문대로 만들면 앱이 마이크를 다시 찾아요. 그래도 안 되면 헤드셋을 뽑았다가 다시 꽂아 보세요.

말하지 않은 글이 입력돼요

Whisper가 숨소리나 웅얼거림을 글로 바꾸는 현상이에요. 안내문에 막는 방법이 들어 있어요. 그래도 생기면 무엇이 입력됐는지 Claude에게 그대로 보여 주세요.

다른 곳을 클릭해서 받아쓴 글이 날아갔어요

입력하고 싶은 곳을 클릭한 뒤, `를 누른 채 ↑로 그 글을 찾아서 Enter를 누르면 돼요.
